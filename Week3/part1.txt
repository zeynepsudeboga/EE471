I refactored conform.py with three platforms, each with one model: Cursor (Grok 4.6 Medium), Antigravity (Gemini 3.1 Pro) and Codex in VS Code (6 Luna Medium).All three replaced the magic values ('H' and the -1 sentinel), removed the duplicated flip-message printing and gave the variables meaningful names, and all three revised scripts produced exactly the same output as the original. Cursor was the most conservative: it split the logic into three small helper functions, kept the public function name and explained every change with its reason. Antigravity was the most thorough and autonomous: it added type hints, docstrings, a __main__ guard and ran 16 test cases on its own. However, it also added a TypeError check that slightly changes behavior, and it verified its result against Cursor's file instead of the original, which showed me that agents read the whole workspace and should be isolated when compared. Codex made the fewest changes: it extracted only one helper and did not run any tests. It also renamed the public function, which could break existing callers, and misread 'H' as "house" instead of "hatless", which is a naming mistake a reader could be misled by. Overall, the agent-based IDEs (Antigravity, Cursor) verified their own work, while Codex required me to test manually. The experience showed that the same prompt leads to different interpretations, so the output of any LLM has to be reviewed and tested by the developer.
