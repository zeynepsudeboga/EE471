Here there is actually the logic of inheritance. In the DVD class, super().checkout() calls the checkout method of the parent class MediaItem. Instead of writing the same code again and again, we call the ready code from the beginning and use it, and then we only add the part that belongs to DVD, which is the "Handle with care" reminder. This gives us practicality. If we change the logic in MediaItem.checkout() later, DVD is also updated automatically, because it calls the parent function directly, so we don't need to change anything in the DVD class.
